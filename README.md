# API Fetch App

This is a front-end web application that fetches and displays data from a public API. It allows users to search for posts by title, view paginated results, and see meaningful error messages if the API call fails or no results are found.

## Features

- Fetches posts from the **JSONPlaceholder API**.
- Implements search functionality to filter posts by title.
- Paginated list of posts.
- Displays a "No results found" message if no posts match the search query.
- Stylish and user-friendly interface using **React** and **TailwindCSS**.

## Installation

### 1. Clone the Repository

To get started with the project locally, clone this repository to your machine:

git clone https://github.com/yourusername/api-fetch-app.git
cd api-fetch-app

2. Install Dependencies
   Install the necessary dependencies using npm:
   npm install

3. Run the Project Locally
   After the dependencies are installed, run the application:
   npm start

This will start the development server and open the app in your default browser at http://localhost:3000.
